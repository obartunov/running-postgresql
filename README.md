# Работающий PostgreSQL

Книга для практика, который эксплуатирует PostgreSQL.

Единица книги — **реальная ситуация работающей системы**, а не фича и не
раздел документации. Каждая глава начинается с того, что человек видит
сам: график, лог, тикет, звонок ночью. Механизм PostgreSQL объясняется
ровно настолько, чтобы действие перестало быть заклинанием.

## Читатель

Senior DBA / SRE, отвечающий за работающую базу. Не разработчик ядра.
Следствия этого решения зафиксированы в [docs/audience.md](docs/audience.md)
и обязательны для всех глав.

## Структура

```
manuscript/        текущая рукопись
experiments/       воспроизводимые стенды, каталоги по номерам глав рукописи
experiments/unplaced/  измеренное, чему в рукописи пока нет главы
docs/              договорённости, указатель измерений, версионные утверждения
drafts/v1-chapters/    первый круг глав, писавшийся до текущей рукописи
research/          исследовательский материал, в текст не идёт
```

Нумерация каталогов в `experiments/` следует главам рукописи. Карта
соответствия и все измеренные числа — в
[docs/measurements.md](docs/measurements.md).

Версионные утверждения, подлежащие сверке перед печатью, собраны в
[docs/version-claims.md](docs/version-claims.md).

## Статус

См. [docs/STATUS.md](docs/STATUS.md).

`drafts/v1-chapters/` — предыдущий круг работы. Текущей рукописью он не
является и в сборку не входит; сохранён потому, что часть измерений и
формулировок пришла оттуда.
