# Стенды

Один каталог на главу. Требования ко всем стендам:

- воспроизводимо на одной машине или VM, без спецжелеза;
- запуск описан в `README.md` каталога полностью, без домысливания;
- прогон сам фиксирует версию сервера, релевантные параметры и хост -
  иначе результат нельзя сравнивать между стендами;
- нагрузка задаётся фиксированным темпом поступления запросов, а не
  "сколько выжмет", если измеряется задержка;
- сырые результаты пишутся в `results/` и не коммитятся;
- всё, что опасно (снятая защита, оставленная подготовленная
  транзакция), помечено в конфиге и в README, выполняется только на
  выбрасываемой базе и убирается за собой.

В текст книги попадают не сырые логи, а сводка: три-четыре числа и
форма графика.
