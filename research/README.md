# Исследовательский материал

Сюда кладётся то, что мы выяснили. В текст книги это не идёт напрямую:
материал попадает в главу только через критерий включения из
`docs/voice.md`.

- `flight-edition.md` — первый полный круг идей книги (5 сентября 2026).
  Содержит семь археологических досье, карту из 30 ситуаций, 12 якорных
  глав и 7 эволюционных линий. Написан исследовательским голосом, не
  голосом книги. Служит источником, а не черновиком глав.
