# Работающий PostgreSQL

Книга для практика, который эксплуатирует PostgreSQL.

Единица книги — **реальная ситуация работающей системы**, а не фича и не
раздел документации. Каждая глава начинается с того, что человек видит
сам: график, лог, тикет, звонок ночью. Механизм PostgreSQL объясняется
ровно настолько, чтобы действие перестало быть заклинанием.

## Читатель

Senior DBA / SRE, отвечающий за работающую базу. Не разработчик ядра.
Следствия этого решения зафиксированы в [docs/audience.md](docs/audience.md)
и обязательны для всех глав.

## Структура

```
chapters/      главы в финальном голосе
experiments/   воспроизводимые стенды, по одному каталогу на главу
docs/          договорённости: голос, читатель, статус
research/      исследовательский материал, в текст не идёт
```

Правило разделения: `research/` — то, что мы выяснили;
`chapters/` — то, что читатель прочтёт. Материал из первого попадает во
второе только через [критерий включения](docs/voice.md).

## Статус

## Сборка

Требуется pandoc.

```sh

```
