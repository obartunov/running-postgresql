# Версионные утверждения: список для сверки перед печатью

Каждая строка — утверждение из рукописи, истинность которого зависит от
версии PostgreSQL. Перед печатью сверяется по release notes или
коммиту; результат проставляется в колонке «сверено».

Статусы: `подтверждено` — сверено по release notes или документации в
ходе работы; `по памяти` — записано без сверки, требует проверки;
`beta` — целевая версия 19 ещё не GA, деталь может измениться.

Целевая версия книги — PostgreSQL 19. На 6 сентября 2026 она в статусе
Beta 3.

## Приложение с release notes

Приложение «Release notes как археологическая карта болей» — самая
проверяемая часть книги: там перечислены десятки версионных фактов от
7.1 до 19. Каждая строка приложения должна получить ссылку на release
notes соответствующей версии или на коммит. Это единственная часть, где
рецензент будет сверять построчно, и единственная, где ошибка стоит
доверия ко всей книге.

Отдельно: у нескольких утверждений в приложении есть шанс оказаться
переупрощениями («в 8.3 появился HOT» — верно; «в 9.6 появился
parallel query» — верно только для части узлов). Формулировки такого
рода стоит проверять не только на дату, но и на объём заявления.
